# Project Overview

## 1. System Objectives

The project aims to develop an online seafood e-commerce platform
that helps fisherfolk manage and present their seafood products
online. It also provides buyers and consumers with a way to view
available seafood products and transactions.

## 2. Proposed Scope

The system will include:

- User Registration and Login
- Seafood Product Management
- Product Listing
- Buyer/Consumer Management
- Transaction Management
- Database Management
- System Integration

### In-Scope

- User account management
- Seafood product management
- Product listing
- Transaction management
- Database integration

### Out-of-Scope

- Physical delivery management
- Offline transactions

## 3. Stakeholders

- Fisherfolk — will use the system to manage and present their
  seafood products.

- Buyers/Consumers — will use the system to view seafood products
  and make transactions.

- System Administrator — will manage users and system data.
